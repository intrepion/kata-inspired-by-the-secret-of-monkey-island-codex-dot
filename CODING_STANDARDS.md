# Standards

Keep game rules in pure typed public domain functions. The view must dispatch those rules rather than mutate progression. Saves are untrusted input and must be validated. Use no runtime dependencies or external image/font requests. HTML templates contain authored identifiers/content; any variable narration or saved content must be escaped before insertion. All pointer actions have named focusable button equivalents. Motion respects prefers-reduced-motion. Tests express specification behavior at public boundaries.
